# Коротка довідка: правки CSS

На основі Roast створено файл `assets/css/hoku.css`. Приклади змін:

1. `background` — шоколадний фон сайту й градієнт hero-блоку (`.hero`).
2. `color` — контрастні бежеві написи й помаранчеві акценти (`.orange`, `.hero h1 em`).
3. `font-size` — збільшені заголовки та основні тексти (`.hero h1`, `.story h2`, `.lead`).
4. `padding` / `gap` — збільшені внутрішні відступи, відстані між блоками.
5. **Самостійно:** `linear-gradient(...)` для помаранчевої кнопки `.button-primary` та правило `.button-primary:hover` для зміни її кольору та `transform:translateY(-3px)` при наведенні.
6. `@media` — адаптивне компонування на екранах 1050, 770 і 480 px.

Файл `assets/css/style.css` — оригінальні стилі Freeframe, що залишилися як базові; додаткові правила HOKU мають перевагу завдяки пізнішому підключенню.
