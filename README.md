# HOKU — specialty coffee / навчальний лендінг

**Версія:** 1.1 — готовий до завантаження на GitHub Pages. Ще не опублікований.

## Походження шаблону

Проєкт створений шляхом редагування безкоштовного HTML + Tailwind шаблону **Roast** від Freeframe: https://freeframe.dev/templates/roast

**Ліцензія оригіналу:** MIT, копія в `LICENSE.txt`. Частину стилів з оригіналу збережено у `assets/css/style.css`. HTML-сторінку перероблено під односторінковий лендінг HOKU. Нові стилі — `assets/css/hoku.css`; функціонал каталогу та демозамовлення — `assets/js/hoku.js`.

## Як переглянути сайт

1. Розпакувати архів.
2. Відкрити `index.html` у браузері. Для перегляду та демонстраційного кошика сервер не потрібен.
3. Для публікації всі файли папки `HOKU` потрібно додати до окремого репозиторію GitHub та ввімкнути GitHub Pages.

Жодні гроші, карткові дані чи замовлення не приймаються. Кошик працює тільки в браузері та використовує `localStorage` для демонстраційних товарів.

## Що змінено у порівнянні з Roast

- Бренд, назва, тексти, посилання навігації і метатеги змінені на **HOKU**.
- Колірна палітра: темний шоколад `#1b100c`, молочно-бежевий `#ead5b9`, помаранчевий `#ed762c`.
- Власний макет матової пачки із широким корпусом, кремовою етикеткою і великим кистьовим логотипом.
- Замість 10 демонстраційних товарів оригіналу — сім країн: Ефіопія, Колумбія, Гондурас, Кенія, Коста-Рика, Руанда, Бразилія.
- Усі пакування збережені у стиснутому форматі WebP, з описовим `alt` у HTML.
- Змінені шрифти, відступи, кольори, фони, градієнт кнопок і `:hover` (властивість, опрацьована самостійно для завдання).
- Адаптивна верстка для мобільних пристроїв і модальні вікна з керуванням з клавіатури.
- Сценарій демонстраційної покупки: перегляд → додавання в кошик → початок оформлення → завершення тестової заявки.
- Обов'язковий навчальний текст розміщений у футері.

## Семантичне ядро (попереднє)

Основні ключові фрази: `спешелті кава`, `кава в зернах`, `кава з Ефіопії`, `кава з Колумбії`, `кава з Кенії`, `кава з Бразилії`, `кава з Гондурасу`, `кава з Руанди`, `кава з Коста-Рики`.

- `title`: HOKU — спешелті кава в зернах із 7 країн світу
- `h1`: СМАК З ІНШИХ ШИРОТ. СПЕШЕЛТІ КАВА В ЗЕРНАХ (остання фраза — видимий підзаголовок у межах h1).
- `description`: опис семи країн і навчального каталогу HOKU.

Це тематичний добір запитів, а не підтверджені дані частотності: інструменти пошукової статистики ще не використовувалися.

## Тестові події для майбутньої GA4

| Дія | Подія |
|---|---|
| Відображення каталогу / фільтра | `view_item_list` |
| Відкриття картки кави | `view_item` |
| Додавання в кошик | `add_to_cart` |
| Відкриття кошика | `view_cart` |
| Початок тестового оформлення | `begin_checkout` |
| Завершення тестового оформлення | `generate_lead` і `demo_order_complete` |

Події поки доступні локально через `document.addEventListener('hoku:analytics', ...)`; зовнішній GA4 отримає їх **лише після додавання справжнього Google tag** (`gtag`). Уся воронка навчальна. Подію реальної покупки `purchase` не надсилаємо.

## Що ще потрібно для виконання незакреслених вимог методички

- Опублікувати **два** окремі репозиторії: вихідний Roast без змін та HOKU після редагування.
- Підключити GA4 і Microsoft Clarity, пройти воронку на опублікованому сайті, зібрати справжні звіти та теплову карту.
- Додати URL оригіналу / відредагованої сторінки і реальні скриншоти до Word-звіту для Moodle.

Пункти про посилання на студентські проєкти, зворотні посилання та скриншот OpenLinkProfiler закреслені у методичці й не виконуються.

Примітка: назви лотів, ціни й смакові дескриптори — навчальні приклади, не характеристика конкретних закуплених зерен.

## Рецепти заварювання HOKU

На сторінці додано окремий розділ `#recipes` з чотирма перемикними рецептами: **AeroPress, V60, French press і Cold brew**. У кожному зазначено масу кави та води, співвідношення (ратіо), температуру, час, помел, поетапний рецепт і рекомендації зерна з колекції. Секція доступна з головної навігації; вкладки працюють за допомогою клавіатури (стрілки, Home, End).

Код перемикання — `assets/js/recipes.js`, стилі — `assets/css/hoku.css`. Параметри є стартовими авторськими рецептами для навчального асортименту, не підмінюють інструкції виробників і не стверджують лабораторно підтверджений профіль конкретного зерна.

Попередні правки збережені: якісніше зображення кавового ландшафту, підпис **Burenko Polina** у футері й відсутність тимчасового блоку «Студентські проєкти».
